# Charter template

Keep the charter to what this assignment needs. Standing AGENTS.md grants and role skills apply without repetition.

## Mission and scope

Name the goal, source plan or bead, completion evidence, and any material boundary. A bounded spec can start directly; plan before writing for a new role, subsystem or one-way door.

## Roster

Name the drivers, reviewers, and conductor, using the staffing defaults in AGENTS.md. Include capacity limits, known seat anomalies, and any exception still in force, each with its source.

## Decisions and continuity

Name the recipients for SCOPE, INCIDENT, ADJUDICATION/human_decision and one-way-door decisions. If a pending decision needs timed escalation, name the actor and wake that will advance it; a timeout alone cannot wake a yielded seat. Keep unrelated work moving. Include actual exceptions to standing authority only when the user imposed them.

## Evidence and reporting

Name the required review ladder, final-head CI receipt and completion artifact. Drivers report one line per pushed head and merge/sync outcomes. Batch other milestones; a working seat’s status reply does not create a heartbeat obligation.

## Optional additions

Add a strategy reference, measurement ledger or special reporting field only when this run uses it. Derive reported counts from bus records and publish the reproducing command. Do not add a second operational ledger when payloads and the PR already hold the record.
