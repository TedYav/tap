# Plays for `/tap:lead`

The menu and each play's trigger are in [`../SKILL.md`](../SKILL.md). A play is opened when its situation arises; none needs to be read in advance, and none requires another.

Several ideas in these plays (the throughput check, one unit before the rest, fresh seats with consolidated scope, owning what delegates produce, side effects over reports, three-valued verdicts, accounting for every seat, retry by cause) are adapted from Lauren Tan's pstack `poteto-mode`, `orchestrate` and `swarm` skills (MIT, Copyright (c) 2026 Lauren Tan; upstream `cursor/plugins`).
