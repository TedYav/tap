**Tuning error classes.** `preset_not_composable` (`--preset` combined with `--model`/`--effort`/`--env`) · `launch_env_forbidden` (an ad-hoc `--env` key crosses the fence) · `launch_effort_unsupported` (`--effort` on a harness with no effort translation) · `launch_model_unsupported` (`--model` on a harness with no model axis) · `launch_arg_invalid` (a malformed tuning argument: `--env` without `=`, an empty value, `--effort` beside explicit passthrough, or a value outside a published domain) · `launch_tuning_not_resumable` (tuning flags on a launch that delegates to resume) · `harness_env_forbidden` (a `[harness.<name>.env]` key crosses the fence) · `retired_flag` (a removed spelling: `--teams` on launch, `--model`/`--teams` on resume and restart). Every one of them names the flag or table the caller actually wrote: the fence is shared across preset tables, ad-hoc flags, the crew door, and the harness tier, so a refusal that named the wrong surface would be well-formed, pass every test, and be impossible to act on.

`tap ask` and `tap crew add` consume this catalog (tap-8nob, tap-4ulb; the `preset_scope` refusal is retired). Both resolve through this same reader, so there is one answer to which file is authoritative and what a malformed one means. Both enforce the completeness rule — `--preset` with ad-hoc tuning refuses `preset_not_composable` — and both check rather than override a disagreeing harness (`preset_harness_mismatch`). Crew refusals are argv-decidable and fire before registry, window, or child-launch effects; ask's fire before its prompt read.

**agy (Antigravity / Gemini) launcher support (tap-8qj7, tap-ppo7).** agy launches with `agy --dangerously-skip-permissions` (omitted under `[harness.agy] permissions = "auto"`; see the harness permission mode) plus `--model`/`--effort` when supplied, translated through the tuning table (`--effort` domain `low|medium|high`; model keys pass through). An explicit verified registry `harness_session_id` resumes with `agy --conversation <uuid>`; otherwise agy's own `--continue` latest behavior is used. Registration captures `ANTIGRAVITY_CONVERSATION_ID` only with environment attribution; derived candidates never become authority. A clean `/exit` ends the pane, and a later current-row resume recreates it.
