**Pane-anchored re-anchor of `unanchored_bus` (tap-7s1r, v0.23).** When the cwd walk refuses `unanchored_bus` and the caller gave no explicit `--team`, pinned root or `paneFallback:false` opt-out, `resolveContext` attempts ONE re-anchor through the calling pane: live marker; pane observed inside tmux; the observed session a `team/handle` HINT ONLY (the handle is never trusted); the authoritative row read under that team scope after pane/session/epoch checks; `contested` and unscoped `unverified` fail the anchor (an unreadable enrolled registry leaves uniqueness unproven; another team's absent one does not, see [stale enrollment](../identity/registry-unit-1-part-07.md)); the cwd shares one git common directory with the enrolled root. Success re-enters the selector through that root with source `pane`. Every miss throws the SAME saved refusal object; each verb recomputes a contest as `pane_contested` with its own exit code. A final exact-team row validation and a second unscoped uniqueness check (tap-sbvgt) precede pinned selection, which binds to that row's canonical registry path; the launcher treats a `pane` source as NOT enrollment and refuses `launcher_unenrolled`. Classifiers treating an unanchored cwd as data (`missingLocalTeam`) opt out.

**Pane precedence over an enrolled cwd (tap-djlri).** A seat is resolved by its pane, never by its cwd; the walk only defaults a team for an unregistered pane. When it selects an enrolled team whose registry holds no active row for the calling pane, the same anchor runs, same controls. An anchor differing from the walk's selection in team, root, registry path/realpath or bus replaces it with source `pane` (a revalidated same-team selection is kept); an identical anchor and every ordinary miss keep the walk's selection and the verb's own refusal. The launcher opts out (record selection is cwd-bound). The observed pane decides, never an inherited `TMUX_PANE`; outside tmux nothing is observed.
