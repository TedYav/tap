# TAP smokes

**Fixture env isolation (tap-o4ae):** smokes that set `TMUX=/fake/socket` (or other fixture vars) via top-level `export` refuse to be `source`d — run them with `bash path/to/smoke.test.sh` only (as `smoke-all` does). Never paste those `export` lines into a long-lived agent shell: a leaked synthetic `TMUX` makes real `tap send`/`tap reply` probes fail open into false `pane_gone` suspensions; lib.sh now refuses that write when the tmux server is unreachable, but the exports still poison `tmux` for the rest of the session. Prefer `TMUX=/fake/socket cmd` prefixes in ad-hoc harnesses, or `unset TMUX` before any real-bus invocation.

- `socket-unreachable-no-suspend.test.sh` — tap-o4ae: `TMUX=/fake/socket` must refuse `pane_gone` suspension (dead socket ≠ dead pane); smokes that export fixture `TMUX` refuse to be sourced.


The entries below are a hand-kept guide, not the inventory: current discovery is `ls skills/*/scripts/smoke/*.test.sh` (what `scripts/smoke-all.sh` globs). Each is named for what it tests (CONTRACT.md). A PR's required evidence is focused runs of the files for what it changed — one `bash scripts/smoke-all.sh --only skills/tap/scripts/smoke/NAME.test.sh` per file; each supplies the sandbox HOME, state paths and private tmux server (see `AGENTS.md § Contributing`). The full suite, `bash scripts/smoke-all.sh`, runs against `main` off the merge path, as a standing post-merge run whose failures are fixed forward.


Courier-heavy smokes that drive the submitter against the mock export `TAP_TUI_SETTLE_SCALE=0.1` near the top: the courier's real-TUI settle sleeps verify nothing against a synchronous mock ([submit-verify settle-delay scaling](../../protocol/delivery/submit-verify-helper-lib-sh-tap-submit-verify-part-02.md)). New tests in that shape should do the same; leave it unset in tests that assert on real timing (e.g. the watch evaluator's timeout ordering).
