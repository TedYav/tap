Install once. Keep the clone.

TAP links your agent tools to a permanent source directory. On a Mac, start with the requirements below.

1 / Prepare your terminal

Rather have an agent do this? Copy the agent prompt from the landing page.

TAP needs Git, Bash 5+, Bun 1.4+, jq, tmux, tar and lsof. It does not need Python. With Homebrew already installed:

brew install git bash jq tmux
brew install oven-sh/bun/bun
export PATH="$(brew --prefix)/bin:$PATH"
hash -r
bash --version
bun --version
jq --version
tmux -V
tar --version

macOS ships an old Bash, so confirm that bash --version reports 5 or newer after the PATH line. On Linux, install the same tools, including lsof, with your package manager and Bun from its official installer; the installation runbook lists the commands.

If brew is missing from PATH, follow Homebrew’s printed shellenv step. Keep the PATH setup in your shell startup file; the guide covers Apple Silicon, Intel and shell differences. Install and sign in to your chosen agent CLIs separately.

2 / Clone and install

git clone https://github.com/TedYav/tap.git ~/tap
cd ~/tap
./install.sh

TAP is beta software; expect bugs. Keep your TAP clone wherever you choose; ~/tap is only an example. The installed command points into that clone. If the installer refuses, follow its exact repair message and rerun it.

3 / Answer the wizard

On a first interactive install without a machine config, the wizard runs automatically. To revisit it: tap setup --machine.

  1. First use in a new project: ask (the default) has TAP ask before it sets up a team; auto sets one up without asking.
  2. Messages that arrive while you type: interrupt (fastest) or wait until your input is empty. Interrupt may clear a draft; see First team for recovery.
  3. Each detected harness: simple starter presets, choose numbered presets, or skip. Skip is the default. Detection checks executables, not login or model access.
  4. Default effort, asked only if you selected Claude/Codex starter presets: default (the harness chooses), low, medium, high or xhigh.
  5. Permission mode for each detected Claude, Codex, Cursor and Antigravity harness: auto or bypass. A saved choice is kept; a new one defaults to auto. See what the modes mean.
  6. Optional full skill kit: no on first setup; later runs keep the saved choice. Notifier: keep the existing setting.
  7. Existing config: update it with a backup, or write a candidate to review. A candidate is not active.
  8. Shell integration for Bash/Zsh, if the active config was written: the wizard shows the startup file and each alias line before asking.
  9. Optional plugins for detected Claude/Codex, offered only if you chose the full skill kit: each plugin is offered separately, and the default is no.

Note: in auto mode you may have to approve the first TAP message, unless you run tap init in the project first.

The wizard opens the getting-started sheet on macOS and prints a launch command for your work directory.

Project instructions

Choose the permission mode yourself: bypass grants the agents your permissions, so enable it only if you accept that. Creating the first team adds TAP instructions to the project’s AGENTS.md, preserving existing instructions. Codex’s automatic reviewer uses this project context for TAP messages in auto mode; no separate setup command is needed.

4 / Verify

export PATH="$HOME/.local/bin:$PATH"
tap help
tap presets

Use the bin path the installer prints if you chose another location. Keep it in your shell startup file if the alias wizard has not already added it. Next: launch your first team.

Where things live

Software

Your TAP clone (for example ~/tap) holds the source. ~/.local/bin/tap links to the command.

Choices

~/.config/tap/config.toml holds machine presets and harness policy (or under $XDG_CONFIG_HOME).

History

~/.tap holds machine state; project .tap/ directories hold team state.

Update or uninstall

cd ~/tap
./install.sh --sync

Run updates from the permanent clone, never a disposable worktree. A refused sync means the update is incomplete.

tap uninstall shows the recorded removal list, asks for confirmation, then offers keep, archive or delete for history and config. Archive writes a tarball before removing originals. Dependencies and plugins remain installed.
