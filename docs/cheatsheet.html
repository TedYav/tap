1 / Install once

Start an installing agent outside the TAP clone and point it at AGENT-SETUP. That runbook owns prerequisites, the permanent clone and permission choices. TAP is a pre-release preview. If cloning fails with a permission error, ask the maintainer for access. Sign in to Claude Code and Codex yourself.

TAP lets agents communicate by injecting keystrokes into one another’s terminals on one machine. If that does not fit your threat model, do not use it. Bypass mode grants the agents your permissions.

2 / Initialize your project

In your project:

cd /path/to/your/project
tap init

tap init initializes Git projects directly and asks before enrolling a directory outside Git. Enrollment details and exceptions →

3 / Launch two seats

Run these in your project terminal, one at a time:

tap launch claude
# After Claude opens, Ctrl-b then d returns to your terminal.
tap launch codex

TAP starts and registers each seat. From a foreground terminal, launch opens the agent. If launched by an agent or without a terminal, visit it with tap attach claude or tap attach codex.

Launch uses your saved permission choice, or auto mode by default. Choose bypass mode before launching if you prefer it. Finish sign-in, folder-trust and hook-review prompts yourself.

4 / Ask one to message the other

See the seats with tap team, then type into either pane, in plain language:

Run tap team to see the roster, then ask the other agent: should our first tiny project start with a README or a test? One sentence of reasoning. Show me its actual reply.

Approve the tap command if your harness asks — in that pane. You finish when the asking pane shows the other agent’s actual answer; a registered seat or queued message is not that answer. If mail arrives while you type, type WAIT (in capitals) to hold deliveries for two minutes. Visit a seat, handle prompts and return later →

When a seat needs you

Detach with Ctrl-b, then d. Run tap team to see the roster and tap attach <seat> to visit a seat by its name.

For Codex’s Hooks need review screen, follow the hook-review handoff. Trust only hooks you intend to trust. Installing TAP does not pre-trust them; declining or skipping leaves TAP’s guard and SessionStart hooks inactive until trusted through Codex review.
