Add a preset

Add a uniquely named table to ~/.config/tap/config.toml (or your XDG config location). For example:

[presets.my-astra]
harness = "codex"
params.model = "gpt-6-astra"
params.config = ["model_reasoning_effort=medium", "service_tier=default"]

Claude uses params.effort = "medium". Cursor and agy encode effort in the model name; OpenCode and Hermes keep provider-specific tuning. A preset is complete: tap session launch refuses --model and --effort alongside one, so edit the preset or choose a different one. It still accepts --env NAME=value for environment variables. tap crew add --preset is stricter and also refuses --env; a crew seat on a bare harness needs an explicit --model.

tap presets
tap session launch my-astra writer

Add a shell shortcut

The setup wizard offers Bash/Zsh aliases for its selected presets. Open a new terminal to load them. For a custom preset, a manual shell alias can be:

alias my-astra='tap session launch my-astra'

Put it in your shell’s startup file to keep it. Then my-astra writer launches that preset as writer. Wizard aliases also support a name suffix: astra review creates astra-review.
