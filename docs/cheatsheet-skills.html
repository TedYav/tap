Find the canonical instructions

Claude and Codex use the native plugin names shown below, such as tap:lead. Other harnesses use flat names such as tap-lead; the all-seat entry is tap. Ask your agent to load the named skill. Some message helpers are agent-invoked rather than slash-menu entries.

tap help skill lead

This command returns the canonical file for your installed TAP version. Open that file before using the skill. Namespaced and flat names resolve there too.

The native plugin exposes the complete set. Flat hosts start with tap, tap-in, tap-send, tap-escalate, tap-config-wizard and tap-help; the full-kit setting adds the rest. Skills are instructions for agents, not a fixed workflow enforced by the transport.

Start and configure

tap:help

Get two harnesses exchanging a real reply, then choose the next useful capability.

Use when you are new to TAP or want it to fit your workflow.

tap help skill help

tap:config-wizard

Choose presets, permissions, notifications, aliases and other machine settings.

Use for first setup or a named setting you want to change.

tap help skill config-wizard

tap:tap

Apply the shared rules for messages, liveness and tree custody.

Use whenever agents coordinate through TAP.

tap help skill tap

tap:in

Register or reconnect the current pane.

Use after pane or session changes, or when registration is uncertain; launched seats are already registered.

tap help skill in

tap:team

Inspect the roster and seat metadata.

Use to choose a recipient or understand who is on the team.

tap help skill team

tap:out

Unregister a seat and free its handle, with an explicit handoff when needed.

Use when leaving the bus or removing an exited teammate.

tap help skill out

Send work and answers

tap:assign

Send a work order with a tracked reply obligation.

Use to ask a teammate to review, fix, build or investigate something.

tap help skill assign

tap:send

Choose a note, a question with an answer owed, or an assignment.

Use to communicate with a seat; an informational note is not a work order.

tap help skill send

tap:reply

Answer an incoming request and settle its obligation.

Use when the payload says reply: expected; a progress reply keeps unfinished work open.

tap help skill reply

tap:outstanding

List messages you sent that still await settlement.

Use before yielding or when checking what you still owe supervision on.

tap help skill outstanding

tap:escalate

Ask the configured notifier to alert the user with a question.

Use when only the user can unblock work; notifier acceptance does not prove they saw it.

tap help skill escalate

Choose a collaboration shape

tap:ask

Run one stateless harness prompt and print its answer.

Use for a bounded question with no follow-up conversation, TAP pane or seat lifecycle.

tap help skill ask

tap:crew

Manage a short-lived consult or review seat in the current tmux session.

Use when a conversation needs follow-up but no durable implementation lane; crews are not parallel writers.

tap help skill crew

tap:collab

Agree who writes, challenges and decides, then choose pair or discuss.

Use when collaborating with a named peer on a bounded task.

tap help skill collab

tap:pair

Coordinate one writer and a partner who independently reviews each published unit.

Use while producing code, prose or research together, with review tied to an exact range.

tap help skill pair

tap:discuss

Resolve a plan, review or decision through bounded exchanges and a driver-owned issue ledger.

Use to converge on finished material; agreement does not itself authorize execution or publication.

tap help skill discuss

tap:adapt

Recompose skills into a written proposal with cuts, preserved requirements and executor routing.

Use for material changes to a skill workflow or a composition across TAP seats; ordinary choices within a skill need no adaptation.

tap help skill adapt

Run the team

tap:lead

Design the team strategy, staffing and independent final gate.

Use when leading a mission or choosing how its work should be delegated.

tap help skill lead

tap:drive

Own an implementation lane, including custody, commits, checks and closeout.

Use when responsible for a lane from assignment through delivery.

tap help skill drive

tap:conduct

Run dispatch, staffing, review routing and milestone reporting under a leader’s charter.

Use when a busy leader delegates the recurring coordination work.

tap help skill conduct

tap:choreography

Coordinate readers, writers, evidence and wakes.

Use for parallel reviews or edits, shared trees, or supervision with a concrete coverage gap.

tap help skill choreography

Preserve continuity

tap:context

Choose the least disruptive recovery: leave alone, compact, clear and rebrief, or restart.

Use at task boundaries or when context threatens reliable work; preserve custody and the standing assignment.

tap help skill context

tap:self

Invoke supported compact, rebrief, goal, loop or clear controls in the current seat.

Use for an authorized self-transition with an authored handoff where required; support varies by harness and arming is not completion.

tap help skill self
