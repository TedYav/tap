Have your agent install it

Paste this into Claude Code, Codex or any agent that can run commands. Start the agent in the folder you want as your first TAP project; it clones TAP somewhere else.

Expect the agent to stop and ask roughly 6 to 8 times: package installs, permission mode, config, tmux settings and a restart. Picking the recommended option is fine for a first try.

Duct tape for agents

TAP is duct tape, not fiber optic, but it works! Modern agents don't need much to coordinate and get work done: a way to reach one another, a clear task, and a few shared rules.

TAP writes messages to local files and types a short notification into the receiving agent’s tmux pane. The agent reads the message and decides what to do. Delivery alone does not prove it processed the message.

Push, not poll: after sending, keep doing useful work that does not depend on the reply. When the answer is needed, yield and let the reply wake the pane. This avoids repeated model turns spent checking for mail; coordination still uses tokens.

Your first reply

After installing TAP, run these in your project terminal:

tap init
tap launch claude
# After Claude opens, Ctrl-b then d returns to your terminal.
tap launch codex

Ask one agent to talk to the other and show you the answer. Done means the answer text in the asking pane. Visit a seat with tap attach claude or tap attach codex.

Launch uses your saved permission choice, or auto mode by default; choose bypass mode before launching if you prefer it. Finish trust and sign-in prompts yourself. Walk through the first reply →

The five levels of TAP

A team with a coach, a nights watch and a context genie feels like working with a crew, and it makes development fun.

LEVEL 1

Two agents, one conversation

Claude talks to Codex. That alone can take a change from an idea to a reviewed implementation.

LEVEL 2

A team in one project

Give seats names and jobs. You can hand off work, track answers and let several writers move at once.

LEVEL 3

Teams across projects

A team in one project can ask another team about the code it owns.

LEVEL 4

Teams that organize themselves

Give a lead a goal. It can split the work, staff lanes and bring their results through review.

LEVEL 5

Teams that run and evolve

Keep a team working through a long backlog, with supervision, handoffs and roles that grow from repeated needs.
